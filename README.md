# Aura Music — Official Landing & Showcase Website

Modern, high-performance showcase website for **Aura Music** (Lossless streaming, offline player, and synchronized lyrics for Android).

## Features
- **AMOLED Glassmorphism Design System**: True-black (`#08090C`) canvas with cyan/violet aurora ambient light.
- **Hero Device Mockup**: Interactive phone player displaying the custom album artwork from phone gallery.
- **Interactive Audio Engine**: Procedural ambient lo-fi music synthesis via Web Audio API (100% offline, zero external audio dependencies).
- **Live Canvas Audio Visualizer**: 3 real-time frequency modes (Equalizer Bars, Radial Orbit, Sine Waveform).
- **Synchronized Lyrics Showcase**: Click-to-seek lyrics synchronization demonstration.
- **Comparison Matrix**: Side-by-side feature comparison with Spotify and Apple Music.
- **Download APK Modal**: Technical specs (v1.2.0, 27.2 MB, Android 8.0+) with waitlist & local mirror options.
- **100% Mobile Responsive**: Tested across smartphone and desktop viewports.

## Running Locally
```bash
cd ~/aura-music-web
python3 -m http.server 8080
```
Open in browser: `http://localhost:8080`
